Comprehensive Help & Tutorials

Both the Web App and Android App include detailed inline help accessible by clicking the ? icon in the top right corner.

Note: The tutorial is specific to the version you are using. Information relevant to mobile apps is omitted in the web-app help, and web-app specific guidance is omitted in the mobile-app help.

Help Topics Covered:
  • What Can the App Do: Overview of the app's main features, use cases, limitations, and monthly translation quotas.
  • How to Use the App: Detailed instructions on taking photos, selecting images, recognizing text, adding titles and descriptions, copying and sharing data, managing history, and checking image processing quotas.
  • How to Use the App: Detailed instructions on entering text, selecting target languages, starting translations, using speech output, and checking translation quotas.
  • How to Use the App: Clear, step‑by‑step instructions for generating QR codes and configuring the app.
    A progress indicator shows the next action — e.g. enter text or an email address, generate the QR code, send it by email, resend, or modify/clear data — so you always know what to do next. This makes the app intuitive for new users.
    The help also explains how to choose print sizes and the differences between PNG and PDF exports.
  • Web Version versus Mobile Version: Benefits and limitations of using the browser-based app versus the mobile app.
  • Technical Information: Information about Google Cloud Vision API for text recognition.
  • Troubleshooting: Solutions for common issues and tips for reliable operation (only available on the mobile version).

Open the Web App and click the ? icon to explore the full help system. You can switch between English and German by changing the language in the settings.

Umfassende Hilfe & Tutorials

Sowohl die Web-App als auch die Android-App enthalten eine ausführliche kontextbezogene Hilfe, die durch Klicken auf das ?-Symbol oben rechts aufgerufen werden kann.

Hinweis: Das Tutorial ist versionsspezifisch. Informationen, die für mobile Apps relevant sind, werden in der Web-App-Hilfe ausgelassen, und webapp-spezifische Hinweise fehlen in der Hilfe der mobilen App.

Behandelte Hilfethemen:
  • Was kann die App: Überblick über die Hauptfunktionen der App, Anwendungsfälle, Einschränkungen und monatliche Übersetzungskontingente.
  • Wie benutze ich die App: Detaillierte Anweisungen zum Erstellen von Fotos, Auswählen von Bildern, Erkennen von Text, Hinzufügen von Titeln und Beschreibungen, Kopieren und Teilen von Daten, Verwalten der Historie und Überprüfen der Bildverarbeitungs-Kontingente.
  • Wie benutze ich die App: Detaillierte Anweisungen zum Eingeben von Text, Auswählen der Zielsprachen, Durchführen von Übersetzungen, Verwenden der Sprachausgabe und Überprüfen der Übersetzungskontingente.
  • Wie benutze ich die App: Klare Schritt‑für‑Schritt‑Anleitungen zum Erstellen von QR‑Codes und zur Konfiguration der App.
    Eine Fortschrittsanzeige zeigt die nächste Aktion an — z. B. Text oder E‑Mail-Adresse eingeben, QR‑Code erzeugen, per E‑Mail versenden, erneut senden oder Daten ändern/löschen — sodass Sie jederzeit wissen, was als Nächstes zu tun ist. Das macht die App besonders für neue Nutzer intuitiv.
    Die Hilfe erläutert außerdem, wie Sie Druckgrößen auswählen und welche Unterschiede zwischen PNG‑ und PDF‑Export bestehen.
  • Web-Version vs. Mobile-Version: Vor- und Nachteile der Nutzung der browserbasierten App gegenüber der mobilen App.
  • Technische Informationen: Informationen zur Google Cloud Vision API für Texterkennung.
  • Fehlerbehebung: Lösungen für häufige Probleme und Tipps für einen zuverlässigen Betrieb (nur in der mobilen Version verfügbar).
Probieren Sie die interaktive Hilfe aus:

Öffnen Sie die Web-App und klicken Sie auf das ?-Symbol, um das vollständige Hilfesystem zu erkunden. Sie können zwischen Englisch und Deutsch wechseln, indem Sie die Sprache in den Einstellungen ändern.

Profi-Tipp: Die Hilfe enthält ein Inhaltsverzeichnis mit Sprungmarken zur schnellen Navigation zu bestimmten Themen.
