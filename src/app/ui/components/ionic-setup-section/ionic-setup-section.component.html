Why are quotas used?

This Ionic Setup app demonstrates how monthly usage quotas can be managed for features that consume limited or paid resources.

Users are notified well before a quota is reached. Once a monthly quota has been exhausted, the affected feature is temporarily unavailable until the beginning of the next month, when all quotas are automatically reset.

The framework supports two types of quotas:

  • Shared monthly quota: A total usage limit shared by all users of the application.
  • Per-user monthly quota: An individual usage limit that prevents a single user from consuming a disproportionate share of the available resources.

Quota configuration used in this demo:
Shared monthly quota: {{ parameters?.maxFeatureCharsTotalPerMonth | number: "1.0-0" : "en" }} characters for all users.
Per-user monthly quota: {{ parameters?.maxFeatureCharsUserPerMonth | number: "1.0-0" : "en" }} characters per user.

How can I check my quota usage?

On the Feature Page

Your current monthly usage is displayed in the expandable Monthly Quota section at the bottom of the feature page.

If either your personal quota or the shared quota is reached, the main feature (for example, Search Related Words) becomes unavailable until the next monthly reset. All other application features remain available.

On the Statistics Page

The Statistics page provides anonymized usage information, including overall quota consumption and aggregated device statistics across all users.

All statistics are collected and displayed in an aggregated form to help protect user privacy.

Welche Einschränkungen und monatlichen Kontingente gelten?
Warum werden Kontingente verwendet?

Diese Ionic Setup‑App zeigt, wie monatliche Nutzungskontingente für ressourcenintensive oder kostenpflichtige Funktionen verwaltet werden können.

Die Benutzer werden rechtzeitig informiert, bevor ein Kontingent erreicht ist. Sobald das monatliche Kontingent erschöpft ist, ist die betroffene Funktion bis zum Beginn des nächsten Monats nicht mehr verfügbar. Alle Kontingente werden automatisch am Monatsbeginn zurückgesetzt.

Das Framework unterstützt zwei Kontingent-Arten:

  • Gemeinsames Monatskontingent: Ein gesamtes Nutzungskontingent, das von allen Nutzern der Anwendung geteilt wird.
  • Monatskontingent je Benutzer: Ein individuelles Nutzungskontingent, das verhindert, dass ein einzelner Nutzer einen unverhältnismäßig großen Anteil der verfügbaren Ressourcen verbraucht.

In dieser Demo-Anwendung wird die folgende Kontingent-Konfiguration verwendet:
Gemeinsames Monatskontingent: {{ parameters?.maxFeatureCharsTotalPerMonth | number: "1.0-0" : "en" }} Zeichen für alle Nutzer.
Monatskontingent je Benutzer: {{ parameters?.maxFeatureCharsUserPerMonth | number: "1.0-0" : "en" }} Zeichen pro Nutzer.

Wie kann ich meinen Kontingentverbrauch prüfen?

Auf der Feature‑Seite

Ihr aktueller monatlicher Verbrauch wird im aufklappbaren Bereich Monatliches Kontingent am Ende der Feature‑Seite angezeigt.

Wenn Ihr persönliches Kontingent oder das gemeinsame Kontingent erreicht ist, wird die Hauptfunktion (z. B. Search Related Words) bis zum nächsten monatlichen Zurücksetzen deaktiviert. Alle anderen Funktionen bleiben verfügbar.

Auf der Statistik‑Seite

Die Statistik‑Seite zeigt anonymisierte Nutzungsdaten, einschließlich Gesamtkontingentverbrauch und aggregierter Geräte‑Statistiken aller Nutzer.

Alle Statistiken werden aggregiert angezeigt, um die Privatsphäre der Nutzer zu schützen.
