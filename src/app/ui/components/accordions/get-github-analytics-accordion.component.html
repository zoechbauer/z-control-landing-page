We track GitHub repository activity and contributions to better understand engagement and development trends across z‑control projects.

GitHub's Insights > Traffic section provides useful metrics, but only for the last 14 days. To keep a longer-term record, Firebase Functions periodically collect these metrics and store them in Firestore. This lets us analyze GitHub activity over time instead of being limited to GitHub's built-in reporting window.

From the dashboard, you can quickly open the GitHub source code for each repository.

Wir erfassen die Aktivität und Beiträge von GitHub-Repositories, um das Engagement und Entwicklungstrends in den z‑control-Projekten besser zu verstehen.

Der Bereich Insights > Traffic von GitHub liefert nützliche Kennzahlen, allerdings nur für die letzten 14 Tage. Um einen längerfristigen Verlauf zu erhalten, sammeln Firebase Functions diese Kennzahlen periodisch und speichern sie in Firestore. So können wir GitHub-Aktivitäten über längere Zeiträume analysieren, statt auf das von GitHub vorgegebene Berichtsfenster beschränkt zu sein.

Über das Dashboard können Sie den Quellcode jedes Repositories schnell in GitHub öffnen.
