What can the app do?

What is this app for?

The app describes and provides all z‑control open source solutions and tools. This information is shown on the app's home page.

In addition, the app provides information about z‑control and about the app itself. This information is shown on the app's settings page.

All apps and tools are free of charge and can be used without registration.

You can select the language (English or German) in the settings.

Highlights:

  • User support:
    Easy to use, with clear navigation and an intuitive design.
  • The app offers comprehensive help pages and guides for all features.
  • You can switch between the various features and settings at any time.
  • User interface:
    Same user interface as in all other z‑control apps.
  • All apps use standardized components and designs so that you can find and use specific features in the apps more easily.
  • Languages:
    Supports English and German.
  • Apps and source code:
    You can use the web version of the app directly, install the Android version, or access the application's source code on GitHub.
  • Free of charge:
    All apps and tools are free of charge and can be used without registration.

How do I use the app?

  • First launch of the app
    • When you first start the app, a notice is displayed telling you that you need to activate Firebase Analytics.
    • Without this consent, the use of the app is limited: you can only access the activation function, the language settings, and the privacy policy.
    • The privacy policy describes how your data is processed.
    • Once you have consented to the use of Firebase Analytics, you can use the app without restrictions.

  • Exploring a specific app

    1. Select the row of the app that you want to explore.
    2. The detail view of the app opens, and the name of the app is shown in the title bar.
    3. In the detail view, you can explore the features of the app.
    4. Switch between the various features of the app by tapping the corresponding accordion to open it.
    5. The first section, "What does the app do", has a different background and always stays open. For the other sections, only the most recently selected accordion is shown.
    6. Finish exploring by closing the detail view.
    7. You can return to the app overview at any time.
  • What do the cloud icons in the overview mean?

    If the cloud icon is shown next to an app in the app overview, this means that the app uses certain functions of the z‑control backend service to process data or provide additional services.

    This information gives users transparency about which apps access the backend functions of z‑control.

    On mobile devices in landscape mode or on large screens, the note "uses z‑control backend functions" is also displayed.

    The app "z‑control Backend Functions" shows the cloud icon so that you can immediately see that this app provides the backend functions.

  • How do I switch between features and settings?
    • On mobile devices in portrait mode: Use the tabs at the bottom of the screen to switch between features and settings.
    • On tablets, desktop PCs, or in landscape mode: Use the button at the top right of the header to switch between features and settings .
    • Use the button at the top right of the header to switch between features and settings .
  • How do I change the app language?

    In the settings, select the option "Select language" to switch between English and German. The change takes effect immediately.

  • Where can I find the apps' privacy policies?

    Every z‑control app has its own privacy policy.

    You can find the privacy policy of this app (z‑control Landing Page App) in the settings under the "Privacy Policy" section. All relevant information about this app's privacy policy is available there.

    You can find the privacy policies of all other z‑control apps in the description of the respective app under the "Show privacy policy" section.

  • Where can I find the GitHub statistics of the z‑control apps and tools?

    You can find the statistics on the "Settings" page in the "GitHub statistics of the z‑control apps and tools" section. This page also provides detailed information and explanations about the statistics.

  • How do I switch between dark and light mode?

    The app follows your device's system settings. Change your device's design ("Dark design", "Light design") in the system settings. The change takes effect immediately.

  • How can I give feedback or contact support?

    You can send us feedback, questions, or suggestions via the email link in the settings. Tap the logo in the header to open the feedback area. You can send us an email via the "z‑control Support" link.

Troubleshooting & Problem Solving

  • Why can't I install the Android app?

    Currently, only the Android version of the z‑control QR Code Generator app has been published on Google Play.

    All other apps are currently available on Google Play as test versions only.

    You can install a test version only if we add you to the test group. To do so, you need to provide us with your email address, as described on the respective app page.

    To install the Android app, make sure that you are using an Android device and that the Google Play Store app is installed.

  • Why is this application displayed so poorly on my phone?

    The application is optimized for mobile display. If it appears squeezed or scaled down, the browser's desktop mode is usually enabled. Make sure the web page is displayed in mobile mode and not in desktop mode.

    Android (Google Chrome)
    1. Open the menu via the three dots ⋮ at the top right, next to the address bar.
    2. Deactivate the option "Desktop site" (in older versions: "Request desktop site").
    3. If necessary, reload the page by tapping the refresh icon in the menu.
    Android (Samsung Internet)
    1. Tap the menu icon ☰ (three lines) at the bottom of the bar.
    2. Deactivate the entry "Desktop version".
    Android (Firefox)
    1. Tap the menu ⋮ at the bottom right.
    2. Deactivate the option "Desktop site".
    iPhone / iPad (Safari)
    1. Tap the "aA" symbol in the address bar.
    2. Select "Request Mobile Website". (If this option is grayed out, mobile mode is already active.)

    Additionally, you can deactivate the option "Automatically Request Desktop Websites" in the section Settings → Safari (from iOS 18: Settings → Apps → Safari) of your device settings so that Safari loads all websites in mobile mode by default.

    If the page is still displayed incorrectly, close the tab completely, reopen the application, and, if necessary, clear the browser cache.

Fehlerbehebung & Problemlösung

  • Warum kann ich die Android-App nicht installieren?

    Derzeit wurde nur die Android-Version der z‑control QR Code Generator App in Google Play veröffentlicht.

    Alle anderen Apps sind derzeit in Google Play nur als Testversion verfügbar.

    Eine Testversion können Sie nur installieren, wenn wir Sie zur Testgruppe hinzufügen. Dazu müssen Sie uns Ihre E-Mail-Adresse mitteilen, wie auf der jeweiligen App-Seite beschrieben.

    Um die Android-App installieren zu können, stellen Sie sicher, dass Sie ein Android-Gerät verwenden und die Google Play Store-App installiert ist.

  • Warum wird diese Anwendung am Handy so schlecht dargestellt?

    Die Anwendung ist für die mobile Darstellung optimiert. Wenn sie gestaucht oder verkleinert erscheint, ist meist der Desktop‑Modus des Browsers aktiviert. Stellen Sie sicher, dass die Webseite im mobilen Modus und nicht im Desktop‑Modus angezeigt wird.

    Android (Google Chrome)
    1. Öffnen Sie das Menü über die drei Punkte ⋮ oben rechts neben der Adressleiste.
    2. Deaktivieren Sie die Option „Desktop‑Version“ (in älteren Versionen: „Website für Desktop“).
    3. Laden Sie die Seite bei Bedarf neu, indem Sie im Menü auf das Aktualisieren-Symbol tippen.
    Android (Samsung Internet)
    1. Tippen Sie auf das Menü-Symbol ☰ (drei Striche) unten in der Leiste.
    2. Deaktivieren Sie den Eintrag „Desktop‑Version“.
    Android (Firefox)
    1. Tippen Sie auf das Menü ⋮ rechts unten.
    2. Deaktivieren Sie die Option „Desktop‑Website“.
    iPhone / iPad (Safari)
    1. Tippen Sie in der Adressleiste auf das Symbol „aA“.
    2. Wählen Sie „Mobile Website anfordern“. (Ist die Option ausgegraut, ist der mobile Modus bereits aktiv.)

    Zusätzlich können Sie in den Geräteeinstellungen unter Einstellungen → Safari (ab iOS 18: Einstellungen → Apps → Safari) im Abschnitt „Desktop‑Websites automatisch anfordern“ die Option deaktivieren, damit Safari alle Webseiten standardmäßig mobil lädt.

    Wird die Seite weiterhin falsch dargestellt, schließen Sie den Tab vollständig, öffnen Sie die Anwendung erneut und leeren Sie gegebenenfalls den Browser‑Cache.
