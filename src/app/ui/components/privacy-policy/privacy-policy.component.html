Optical Character Recognition (OCR): The text recognition is performed via the Google Cloud Vision API. Image data is transmitted to the cloud for recognition. The recognized texts are not permanently stored in the cloud or shared with third parties; further processing takes place exclusively locally on your device.

Image Compression: Images are compressed before processing to improve performance and reduce storage requirements. This is done exclusively locally on your device using ImageManipulator for mobile devices and pica for the web app. No images are stored in the cloud.

Anonymous usage statistics: We store the following anonymous data in Google Firebase/Firestore:

  • Device information (platform type)
  • Number of image processes
  • Date of last image processing
  • Anonymized user ID

This data is used solely to manage monthly usage quotas and prevent unexpected costs. No personal or sensitive data is stored.

You can find the complete privacy policy on the z‑control website Privacy Policy

Die Texterkennung (OCR) erfolgt über die Google Cloud Vision API. Bilddaten werden zur Erkennung in die Cloud übertragen. Die erkannten Texte werden nicht dauerhaft in der Cloud gespeichert oder an Dritte weitergegeben; die Weiterverarbeitung erfolgt ausschließlich lokal auf Ihrem Gerät.

Bilder werden vor der Verarbeitung komprimiert, um die Leistung zu verbessern und den Speicherbedarf zu reduzieren. Dies erfolgt ausschließlich lokal auf Ihrem Gerät mittels ImageManipulator für mobile Geräte und pica für die Web-App. Es werden keine Bilder in der Cloud gespeichert.

  • Datum der letzten Bildverarbeitung
  • Anonymisierte Benutzer-ID
