{{ "MAIN.ACCORDION.WHAT_DOES_APP_DO" | translate }}

The z‑control Image to Text app allows you to extract text from an image.

You can take a photo or select an image from your device. The app recognizes the text contained in the image using optical character recognition (OCR) and then displays it with statistics such as the number of words, lines, and characters.

The data are automatically stored locally on your device. The data is not stored in the cloud, and you can view, edit, copy, share, or delete saved entries at any time.

✨ Highlights:

  • Recognize text in images
    The app recognizes the text contained in the image and displays the result with statistics such as the number of words, lines, and characters.
  • Add additional information
    Optional add a title and a description to describe the photo.
  • Manage history
    View previously processed images and their associated information. You can edit or delete individual entries or the entire history.
  • Copy and share data
    Choose whether you want to copy / share the image, title, description, recognized text, text statistics, and creation and modification dates.
  • Status display
    The status display guides you step by step through the processing procedure.
  • App language
    You can choose German or English as the app language.
{{ "MAIN.ACCORDION.LIMITATIONS_AND_QUOTAS" | translate }}
Limitations:

All users can collectively process a maximum of: {{ parameters?.maxImageProcessingTotalPerMonth | number: "1.0-0" : "en" }} images per month. If this quota is exceeded, costs will be incurred for z‑control.

To manage this shared quota, each user is limited to processing a maximum of {{ parameters?.maxImageProcessingUserPerMonth | number: "1.0-0" : "en" }} images per month, ensuring fair access for all users.

Since image processing is a paid service, quotas are necessary. The app will notify you well in advance when approaching the limit and will prevent further image processing once the monthly quota is exhausted.

Whenever you reach the monthly quota, you can continue to use the app for free, but image processing will be disabled until the quota resets on the 1st of the next month. You can always view, edit, copy, and share previously processed images and their associated information.

How do I check my monthly translation quota?

On the image processing page

Your current image processing quota is displayed at the bottom of the image processing page in an expandable Monthly Quota section.

On the Statistics page in Settings

View detailed, anonymized statistics showing the overall monthly quota usage and device information across all users. All data is aggregated to protect your privacy.

{{ "MAIN.ACCORDION.DIFFERENCES_WEB_MOBILE" | translate }}
Mobile version / native app

The native app is currently available only as a test version for a limited number of users. Access requires an email request to z‑control.

JPEG images can currently only be copied in the native app.

Taking photos is generally easier with a mobile device.

In the native app, the selected data can be sent directly to another app using the sharing function.

Web version

The web version does not need to be installed and can be used directly in a browser.

When using the web version on a PC or notebook, PNG images taken with the camera can be copied.

When using the web version in a mobile browser, images currently cannot be copied. However, the recognized text, title, description, and creation and modification dates can be copied.

IMPORTANT

When accessing the web version on your phone, ensure it displays in mobile mode (not desktop mode) for optimal experience. Mobile mode provides a native app-like interface and enables voice input through your keyboard.

{{ "MAIN.ACCORDION.WHAT_DOES_APP_DO" | translate }}

Die z‑control Image to Text App ermöglicht es, Texte aus einem Bild zu extrahieren.

Sie können ein Foto aufnehmen oder ein Bild von Ihrem Gerät auswählen. Die App erkennt mittels optischer Zeichenerkennung (OCR) den im Bild enthaltenen Text und zeigt ihn zusammen mit Statistiken wie Anzahl der Wörter, Zeilen und Zeichen an.

Die Daten werden automatisch lokal auf Ihrem Gerät gespeichert. Die Daten werden nicht in die Cloud übernommen; Sie können gespeicherte Einträge jederzeit ansehen, bearbeiten, kopieren, teilen oder löschen.

✨ Highlights:

  • Text in Bildern erkennen
    Die App erkennt den im Bild enthaltenen Text und zeigt das Ergebnis mit Statistiken wie Wortanzahl, Zeilen und Zeichen an.
  • Zusätzliche Informationen hinzufügen
    Optional können Sie dem Foto einen Titel und eine Beschreibung hinzufügen.
  • Verlauf verwalten
    Betrachten Sie zuvor verarbeitete Bilder und die zugehörigen Informationen. Einzelne Einträge oder der gesamte Verlauf können bearbeitet oder gelöscht werden.
  • Daten kopieren und teilen
    Wählen Sie aus, ob Sie das Bild, den Titel, die Beschreibung, den erkannten Text, die Textstatistiken sowie Erstellungs‑ und Änderungsdaten kopieren/teilen möchten.
  • Statusanzeige
    Die Statusanzeige führt Sie Schritt für Schritt durch den Verarbeitungsablauf.
  • App‑Sprache
    Sie können Deutsch oder Englisch als App‑Sprache wählen.
Welche Einschränkungen und Monatskontingente gibt es?
Einschränkungen:

Alle Nutzer gemeinsam können pro Monat maximal {{ parameters?.maxImageProcessingTotalPerMonth | number: "1.0-0" : "en" }} Bilder verarbeiten. Wird dieses Kontingent überschritten, entstehen Kosten für z‑control.

Zur Verwaltung dieses gemeinsamen Kontingents ist jeder Nutzer auf maximal {{ parameters?.maxImageProcessingUserPerMonth | number: "1.0-0" : "en" }} Bilder pro Monat begrenzt, um einen fairen Zugriff für alle zu gewährleisten.

Da die Bildverarbeitung ein kostenpflichtiger Dienst ist, sind Kontingente erforderlich. Die App benachrichtigt Sie recht zeitig vor Erreichen des Limits und verhindert weitere Bildverarbeitungen, sobald das Monatskontingent erschöpft ist.

Sobald Sie das Monatskontingent erreicht haben, können Sie die App weiterhin kostenlos nutzen; die Bildverarbeitung wird jedoch bis zum Reset des Kontingents am 1. des nächsten Monats deaktiviert. Sie können stets zuvor verarbeitete Bilder und deren Informationen anzeigen, bearbeiten, kopieren und teilen.

Wie überprüfe ich mein monatliches Kontingent?

Auf der Bildverarbeitungsseite

Ihr aktuelles Bildverarbeitungs‑Kontingent wird unten auf der Bildverarbeitungsseite in einem aufklappbaren Abschnitt Monatliches Kontingent angezeigt.

Auf der Statistikseite in den Einstellungen

Dort sehen Sie detaillierte, anonymisierte Statistiken zur monatlichen Kontingentnutzung und Geräteinformationen. Alle Daten werden aggregiert, um Ihre Privatsphäre zu schützen.

Mobile Version / native App

Die native App ist derzeit nur als Testversion für eine begrenzte Anzahl von Benutzern verfügbar. Der Zugang erfordert eine E‑Mail‑Anfrage an z‑control.

JPEG‑Bilder können momentan nur in der nativen App kopiert werden.

Das Aufnehmen von Fotos ist auf mobilen Geräten in der Regel einfacher.

In der nativen App können ausgewählte Daten direkt an andere Apps über die Freigabefunktion gesendet werden.

Web‑Version

Die Web‑Version muss nicht installiert werden und kann direkt im Browser verwendet werden.

Bei Verwendung der Web‑Version auf PC oder Notebook können PNG‑Bilder, die mit der Kamera aufgenommen wurden, kopiert werden.

Bei Nutzung der Web‑Version im mobilen Browser können Bilder derzeit nicht kopiert werden. Der erkannte Text, Titel, Beschreibung sowie Erstellungs‑ und Änderungsdaten können jedoch kopiert werden.

WICHTIG

Wenn Sie die Web‑Version auf Ihrem Telefon öffnen, stellen Sie sicher, dass sie im mobilen Modus (nicht Desktop‑Modus) angezeigt wird, um die beste Benutzererfahrung zu erhalten. Der mobile Modus bietet eine native App‑ähnliche Oberfläche und ermöglicht Spracheingabe über Ihre Tastatur.
