z-control Backup Scripts
Automate backups, cleanup, and disk-usage logging

z-control Backup Scripts is an open-source collection of PowerShell and batch utilities for Windows that automate backups, cleanup, and disk-usage reporting. Use them to:

✨ Highlights

  • Back up development projects
    with exclusions for build/dependency folders
  • Back up non-committed files
    such as .env, .vscode, etc.
  • Clean up dev folders
    remove node_modules, dist, etc. recursively
  • Log disk/folder usage
    CSV reports for auditing and cleanup
  • Automate tasks
    schedule scripts via Windows Task Scheduler, or run them interactively
  • Documentation & PowerShell compatibility
    Each script is documented, and all scripts are compatible with PowerShell 5 and 7.

✨ Typical use cases:

  • Automated project backups (with logs)
  • Quickly reclaim disk space in dev folders
  • Audit disk usage for large folders
  • Back up important files before deleting or migrating projects

Getting started is easy:
  1. Download the scripts from GitHub or your project repository.
  2. Review the included markdown guides for each script type.
  3. Customize parameters as needed (source, destination, log file, etc.).
  4. Run interactively or schedule via Windows Task Scheduler.
  5. View logs and CSV reports for results and auditing.

For step-by-step instructions, open the relevant documentation using the buttons above.

Automation with Windows Task Scheduler

You can use all batch scripts in a Windows Scheduled Task to automate backups.

Set the task to run the batch file at your preferred schedule.

Ensure the user account running the task has permission to access the source and backup directories.

z-control Backup Scripts
Backups, Bereinigung und Festplattenauswertung automatisieren

z-control Backup Scripts ist eine Open-Source-Sammlung von PowerShell- und Batch-Skripten für Windows, die Backups, Bereinigungen und Festplattenauswertungen automatisieren. Damit können Sie:

✨ Highlights

  • Entwicklungsprojekte sichern
    unter Ausschluss von Build-/Abhängigkeitsordnern
  • Nicht committete Dateien sichern
    wie .env, .vscode usw.
  • Entwicklungsordner bereinigen
    node_modules, dist usw. rekursiv entfernen
  • Festplatten-/Ordnerauslastung protokollieren
    CSV-Berichte für Prüfung und Bereinigung
  • Aufgaben automatisieren
    Skripte über die Windows Aufgabenplanung zeitgesteuert ausführen oder interaktiv starten
  • Dokumentation & PowerShell-Kompatibilität
    Jedes Skript ist dokumentiert, und alle Skripte sind mit PowerShell 5 und 7 kompatibel.

✨ Typische Anwendungsfälle:

  • Automatisierte Projekt-Backups (inkl. Protokollen)
  • Speicherplatz in Entwicklungsordnern schnell freigeben
  • Festplattenauslastung großer Ordner prüfen
  • Wichtige Dateien vor dem Löschen oder Migrieren von Projekten sichern

✨ Dokumentation (englisch):

Die Dokumentationen sind nur auf Englisch verfügbar.

Erste Schritte sind einfach:
  1. Laden Sie die Skripte von GitHub oder Ihrem Projekt-Repository herunter.
  2. Lesen Sie die mitgelieferten Markdown-Anleitungen für jeden Skripttyp.
  3. Passen Sie die Parameter bei Bedarf an (Quelle, Ziel, Protokolldatei usw.).
  4. Führen Sie sie interaktiv aus oder planen Sie sie über die Windows-Aufgabenplanung.
  5. Prüfen Sie Protokolle und CSV-Berichte für Ergebnisse und Nachvollziehbarkeit.

Schritt-für-Schritt-Anleitungen finden Sie in der jeweiligen Dokumentation über die Schaltflächen oben.

Automatisierung mit der Windows-Aufgabenplanung

Sie können alle Batch-Skripte in einer Windows-Geplanten Aufgabe verwenden, um Backups zu automatisieren.

Legen Sie fest, dass die Aufgabe die Batch-Datei nach Ihrem gewünschten Zeitplan ausführt.

Stellen Sie sicher, dass das ausführende Benutzerkonto Berechtigungen für den Zugriff auf Quell- und Backup-Verzeichnisse hat.
