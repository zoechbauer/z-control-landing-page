What are QR codes and how can you use them?

QR codes (Quick Response Codes) are two-dimensional barcodes that store information in a square pattern. They can be read with a camera or QR code scanner and provide quick access to information, websites, or actions.

What can the z‑control QR Code Generator app do?

This app lets you generate QR codes from any plain text you enter. You can use it to:

  • Share simple messages or notes: Encode any text and let others scan it to read your message.
  • Share links: Paste a website URL as plain text, and the QR code opens the link when scanned.
  • Label items: Print QR codes with custom text to label documents, objects, or locations.
  • Transfer information: Quickly move text between devices by scanning the QR code.

Note: Unlike some other QR code apps, this app does not support special QR code formats for contacts, emails, Wi-Fi, or calendar events. All QR codes generated by this app contain only the plain text you enter.

How does it work?
  1. Enter your text: Type or paste any text (up to {{ parameters?.maxInputLength }} characters).
  2. Generate the QR code: Tap the "Generate" button to create a QR code from your text.
  3. Send or print:
    • You can email the QR code as an image or PDF, or print it for use on labels, cards, or documents.
    • You can also share the QR code via messaging apps or social media.
    • You can set the size and number of QR codes per page in the print settings.
  4. Scan to retrieve: Anyone can scan the QR code with a standard QR code reader to view the plain text you entered.
Why use plain-text QR codes?
  • Simplicity: No special formatting or technical knowledge required.
  • Privacy: The app does not store or process your data externally.
  • Flexibility: Use QR codes for any purpose where sharing plain text is helpful.

In summary: This app is designed for users who want a simple, reliable way to generate and share QR codes containing plain text — no more, no less.

Mobile App

Web-specific information is omitted from this help page — consult the web app for platform-specific details and instructions.

Web App

The browser or operating system opens the registered email client. On desktop systems, this is either the system's default mail client or a webmail interface configured in the browser.

For privacy and security reasons, browsers cannot attach files automatically to emails. Therefore, you must manually add the QR code files from the Downloads folder as attachments. Browsers also cannot delete files automatically; cleanup must be done manually.

The email body includes references to both QR code files (PDF and PNG), the QR code text, and shortened printing instructions. Because sending is done via mailto:, the mail body is length-limited; typically only the first ~400 characters (of a maximum of 1000) of the QR code text and a reduced printing instruction are included.

The web app is platform-independent and requires no installation. It can be used directly in the browser but requires an internet connection.

Was sind QR-Codes und wie können Sie sie verwenden?

QR-Codes (Quick Response Codes) sind zweidimensionale Barcodes, die Informationen in einem quadratischen Muster speichern. Sie können mit einer Kamera oder einem QR-Code-Scanner gelesen werden und ermöglichen schnellen Zugriff auf Informationen, Webseiten oder Aktionen.

Was kann die z‑control QR Code Generator App?

Mit dieser App können Sie aus beliebigem unformatiertem Text QR-Codes erzeugen. Sie können damit:

  • Einfache Nachrichten teilen: Kodieren Sie Text, damit andere ihn durch Scannen lesen können.
  • Links teilen: Fügen Sie eine URL als Klartext ein; der QR-Code öffnet den Link beim Scannen.
  • Gegenstände kennzeichnen: Drucken Sie QR-Codes mit eigenem Text zum Beschriften von Dokumenten, Objekten oder Orten.
  • Informationen übertragen: Übertragen Sie schnell Text zwischen Geräten durch Scannen des QR-Codes.

Hinweis: Im Gegensatz zu einigen anderen QR-Code-Apps unterstützt diese App keine speziellen QR-Code-Formate für Kontakte, E-Mails, WLAN oder Kalenderereignisse. Alle QR-Codes enthalten ausschließlich den von Ihnen eingegebenen Text.

Wie funktioniert es?
  1. Text eingeben: Tippen oder fügen Sie Klartext ein (bis zu {{ parameters?.maxInputLength }} Zeichen).
  2. QR-Code erzeugen: Tippen Sie auf "Generieren", um aus dem Text einen QR-Code zu erstellen.
  3. QR-Code senden oder drucken:
    • Sie können den QR-Code per E-Mail als Bild oder PDF versenden oder ihn zum Drucken verwenden.
    • Sie können den QR-Code auch über Messenger-Dienste oder soziale Netzwerke teilen.
    • In den Druckeinstellungen legen Sie Größe und Anzahl der QR-Codes pro Seite fest.
  4. QR-Code scannen: Jeder kann den QR-Code mit einem Standard-Scanner lesen, um den eingegebenen Text anzuzeigen.
Warum QR-Codes aus unformatiertem Text?
  • Einfachheit: Keine spezielle Formatierung (z. B. Rich Text) oder technisches Wissen erforderlich.
  • Datenschutz: Die App speichert oder verarbeitet Ihre Daten nicht extern.
  • Flexibilität: Verwenden Sie QR-Codes überall dort, wo unformatierter Text sinnvoll ist.

Zusammenfassung: Diese App richtet sich an Nutzer, die eine einfache, zuverlässige Möglichkeit suchen, QR-Codes mit unformatiertem Text zu erzeugen und zu teilen.
