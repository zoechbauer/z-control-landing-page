Shared backend code across z-control apps

z-control Backend Functions is the shared backend repository for z‑control applications.

It contains the canonical backend logic used across multiple apps, including Firebase Cloud Functions, Firestore utilities, and related backend helpers.

Development workflow

When you need backend changes for a frontend app:

  1. Implement the shared backend change in this repository.
  2. Run and verify the backend locally with the Firebase emulators.
  3. Connect the target frontend app to the emulator backend.
  4. Test the frontend/backend integration.
  5. Deploy Firebase Functions from this repository only.
  6. Deploy the frontend app separately after backend validation.
GitHub Analytics for z‑control repositories

We track GitHub repository activity and contributions to better understand engagement and development trends across z‑control projects.

GitHub's Insights > Traffic section provides useful metrics, but only for the last 14 days. To keep a longer-term record, Firebase Functions periodically collect these metrics and store them in Firestore. This lets us analyze GitHub activity over time instead of being limited to GitHub's built-in reporting window.

From the dashboard, you can quickly open the GitHub source code for each repository.

Entwicklungs-Workflow

Wenn Sie Backend-Änderungen für eine Frontend-App benötigen:

  1. Implementieren Sie die geteilte Backend-Änderung in diesem Repository.
  2. Führen Sie das Backend lokal mit den Firebase-Emulatoren aus und verifizieren Sie es.
  3. Verbinden Sie die Ziel-Frontend-App mit dem Emulator-Backend.
  4. Testen Sie die Frontend-/Backend-Integration.
  5. Deployen Sie Firebase Functions ausschließlich aus diesem Repository.
  6. Deployen Sie die Frontend-App erst nach der Backend-Validierung separat.
GitHub-Analysen für z‑control-Repositories

Wir erfassen die Aktivität und Beiträge in GitHub-Repositories, um das Engagement und die Entwicklungstrends in z‑control-Projekten besser zu verstehen.

Der Bereich Insights > Traffic von GitHub liefert nützliche Kennzahlen, jedoch nur für die letzten 14 Tage. Um einen längerfristigen Verlauf zu speichern, sammeln Firebase Functions diese Kennzahlen regelmäßig und speichern sie in Firestore. So lässt sich die GitHub-Aktivität über die Zeit analysieren, anstatt auf das integrierte GitHub-Berichtsfenster beschränkt zu sein.

Über das Dashboard können Sie den GitHub-Quellcode für jedes Repository schnell öffnen.
