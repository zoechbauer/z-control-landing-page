🔒 Privacy & Data Security

This privacy policy explains how the z‑control Image to Text App collects, uses, and protects your data.

📱 Data Collection

  • No personal data: We do not collect any personal data unless you explicitly provide it.
  • Optical Character Recognition (OCR): The text recognition is performed via the Google Cloud Vision API. Image data is transmitted to the cloud for recognition. The recognized texts are not permanently stored in the cloud or shared with third parties; further processing takes place exclusively locally on your device.
  • Image Compression: Images are compressed before processing to improve performance and reduce storage requirements. This is done exclusively locally on your device using ImageManipulator for mobile devices and pica for the web app. No images are stored in the cloud.
  • Anonymous usage statistics: We store the following anonymous data in Google Firebase/Firestore:
    • Device information (platform type)
    • Number of image processes
    • Date of last image processing
    • Anonymized user ID
    This data is used solely to manage monthly usage quotas and prevent unexpected costs. No personal or sensitive data is stored.

💾 Local Data Storage

  • Device storage: All settings are stored exclusively on your device.

🌐 Web App vs. Mobile App

  • Web App: Uses the browser's local storage.
  • Mobile App: Uses the device's IndexedDB storage.
  • No cloud synchronization: Your personal settings and data are never synchronized between devices. Only anonymous usage statistics are stored in the cloud for quota management.

🔓 Open Source Transparency

This app is open source. You can view the source code on GitHub to verify our privacy practices and how anonymous statistics are handled.

👶 Children's Privacy

Our app is suitable for users of all ages. We do not knowingly collect personal information from children under 13 years of age without parental consent.

🔄 Changes to this Policy

We may update this privacy policy from time to time. We will inform users of significant changes via the app or our website.
