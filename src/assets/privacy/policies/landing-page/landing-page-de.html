3. Firebase Analytics

Auf dieser Website verwenden wir Firebase Analytics, einen Analysedienst von Google. Firebase Analytics dient dazu, die Nutzung unserer Website sowie der darüber angebotenen Anwendungen und Tools statistisch auszuwerten und unsere Angebote weiterzuentwickeln.

Dabei können beispielsweise Informationen darüber verarbeitet werden, welche Funktionen oder Bereiche genutzt werden, welche Ereignisse in unseren Anwendungen ausgelöst werden und unter welchen technischen Bedingungen die Website bzw. die Anwendungen genutzt werden.

Firebase Analytics kann neben den von uns ausgelösten Ereignissen auch automatisch bestimmte Nutzungsdaten und technische Informationen erfassen. Dazu können beispielsweise Informationen zum verwendeten Gerät, Browser, Betriebssystem, Sprache, ungefährem Standort bzw. Herkunftsland sowie technische Kennungen gehören.

Wir übermitteln über unsere eigenen Analytics-Ereignisse keine von Ihnen aktiv eingegebenen personenbezogenen Daten wie Namen, E-Mail-Adressen, Telefonnummern oder Passwörter.

Wir verwenden keine von uns selbst vergebenen Benutzer-IDs und führen die über Firebase Analytics erhobenen Daten nicht mit personenbezogenen Daten aus anderen Quellen zusammen.

4. Aktivierung von Firebase Analytics

Die Datenerfassung durch Firebase Analytics ist auf unserer Website standardmäßig deaktiviert.

Beim Start der Website wird die Analytics-Datenerfassung zunächst ausdrücklich deaktiviert. Eigene Analytics-Ereignisse werden erst an Firebase übermittelt, wenn Sie die Analytics-Erfassung über die dafür vorgesehene Einstellung aktivieren.

Die Aktivierung von Analytics ist freiwillig. Sie ist jedoch erforderlich, um die über die Landing Page angebotenen Anwendungen und Tools vollständig erkunden und nutzen zu können.

Wenn Analytics deaktiviert ist, werden von unserer Anwendung keine eigenen Analytics-Ereignisse an Firebase übermittelt.

Die technische Steuerung erfolgt über die Firebase-Funktion setAnalyticsCollectionEnabled(). Diese Funktion ermöglicht es, die Analytics-Datenerfassung zu deaktivieren und nach einer entsprechenden Zustimmung wieder zu aktivieren.
