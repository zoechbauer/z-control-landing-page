3. Firebase Analytics

On this website, we use Firebase Analytics, an analytics service provided by Google. Firebase Analytics is used to statistically analyze the use of our website and the applications and tools offered through it, and to further develop our services.

This may include processing information about which features or areas are used, which events are triggered in our applications, and under which technical conditions the website or applications are used.

In addition to the events triggered by us, Firebase Analytics may automatically collect certain usage data and technical information. This may include, for example, information about the device used, browser, operating system, language, approximate location or country of origin, as well as technical identifiers.

Through our own Analytics events, we do not transmit personal data that you actively enter, such as names, email addresses, telephone numbers, or passwords.

We do not use user IDs assigned by us, nor do we combine data collected via Firebase Analytics with personal data from other sources.

4. Activation of Firebase Analytics

Data collection by Firebase Analytics is disabled by default on our website.

When the website starts, Analytics data collection is explicitly disabled initially. Our own Analytics events are only transmitted to Firebase after you enable Analytics collection using the corresponding setting.

Activation of Analytics is voluntary. However, it is required to fully explore and use the applications and tools offered through the Landing Page.

When Analytics is disabled, our application does not transmit any of its own Analytics events to Firebase.

The technical control is implemented using the Firebase function setAnalyticsCollectionEnabled(). This function allows Analytics data collection to be disabled and, after the corresponding consent has been given, enabled again.

5. Purpose of Processing

Processing through Firebase Analytics is carried out in particular for the following purposes:

  • analyzing the use of the website and applications;
  • identifying frequently used features and areas;
  • improving user-friendliness;
  • identifying and resolving technical or functional problems;
  • further developing existing features and developing new features;
  • statistical analysis of usage.

6. Advertising and Marketing

The data collected through Firebase Analytics is used exclusively to analyze usage, improve our applications and tools, and further develop our services from a technical perspective.

We do not use Firebase Analytics for personalized advertising, remarketing, or other advertising purposes. In particular, we do not use a Google Ads integration, Google Signals, or other Google Analytics Advertising Features.

We do not use the data collected through Firebase Analytics to send you advertising or promotional emails.

The applications and tools provided by z-control are offered free of charge and are not financed through advertising within the applications or through personalized advertising based on data collected via Firebase Analytics.

Activating Firebase Analytics therefore does not mean that you are signing up for a newsletter, promotional emails, or any other marketing service.
